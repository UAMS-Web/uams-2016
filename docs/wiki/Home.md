# UAMS 2016 theme wiki

<!-- cspell:ignore UAMS -->

This wiki is the documentation of the UAMS 2016 theme ("Back to the 5"): the reference for its widgets, shortcodes and features, and what to check when one of them does not work. The dashboard's **Documentation** page shows the same Widgets, Shortcodes and Features pages. Installing the theme and developing it are described in the [README](https://github.com/UAMS-Web/uams-2016/blob/master/README.md).

Written against v1.3.0.8.

## Getting started

- [Installation (README)](https://github.com/UAMS-Web/uams-2016/blob/master/README.md#quick-start): download the theme into `wp-content/themes` and activate it.
- [YouTube API key](Shortcodes.md#youtube): the setting the `[youtube]` shortcode needs before it shows anything.

## Reference

- [Widgets](Widgets.md): the widgets the theme registers and their options.
- [Shortcodes](Shortcodes.md): the shortcodes the theme registers, with their attributes and examples.
- [Features](Features.md): widget visibility, media credits and the CSS helper classes.

## Troubleshooting

- [Troubleshooting](Troubleshooting.md): what to check when a shortcode or widget shows nothing or shows an error.

## Project

- [Reporting a bug (README)](https://github.com/UAMS-Web/uams-2016/blob/master/README.md#bugs-and-feature-requests): where to send bugs and feature requests.
- [Contributing](https://github.com/UAMS-Web/uams-2016/blob/master/CONTRIBUTING.md): the issue to pull request path for changes to the theme.
- [Development and tests (README)](https://github.com/UAMS-Web/uams-2016/blob/master/README.md#running-the-tests): requirements, the test suites and the code-quality tools.
